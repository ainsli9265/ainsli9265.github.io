Honestly I was aiming to recreate the crackling fire sound from the book, but it ended up sounding more like popcorn so I leaned into that. The program has a base sound of a brown noise loop made using the code provided in the assignment. I thought it sounded less sharp and bright than white noise. The audio switches between this state and the crackle state. There is a white noise buffer that is used only for randomization and doesn't actually produce audio. Using white noise with a lowpass filter and watching the signal for when it crosses a specific value to generate random timings was mentioned in the book. There is also a function env() to create a short amplitude envelope using setValueCurveAtTime that shapes the crackles. The peak amplitude is randomized per event so some are more faint and some are more sharp. The duration is also randomized. Each crackle also gets a bandpass filter with a center frequency and resonance that are randomized per event.
